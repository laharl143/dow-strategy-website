# Static React SPA, no backend, browser-only persistence

This is a solo-use planning tool (drag hero/item icons onto a fixed 9-slot board), not a public reference site. We chose React + Vite + dnd-kit, built as a static bundle and deployed to Vercel with no server component: all state (the active board, named saved strategies) lives in the browser via localStorage, with no accounts, database, or API. TypeScript throughout for the Hero/Item/Board/SavedStrategy data shapes. Hero and item icons hotlink Valve's Dota 2 CDN rather than being hosted in the repo. This was chosen over a server-backed app (with real persistence, multi-device sync, or public content) because the tool has exactly one user, on one machine, and a backend would add deployment/maintenance cost with no corresponding benefit. Revisit if this ever needs multi-device sync, real backup, sharing with others, or moves toward the originally-considered public wiki/reference-site direction.

To keep that migration cheap, persistence is accessed only through a small interface (`loadBoard`/`saveBoard`/`listSavedStrategies`/`saveStrategy`, etc.) — components never call `localStorage` directly. Swapping to a real backend later means changing the inside of those functions, not the UI that calls them.
